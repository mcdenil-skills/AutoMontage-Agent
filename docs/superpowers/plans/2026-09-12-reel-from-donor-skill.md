# План: reel-from-donor

**Цель:** закрепить методологию «донор → проверенные живые карточки → утверждённая анимация» как общий навык AutoMontage-Agent.

1. Создать канонический `skills/reel-from-donor` с картой донора, контентным контрактом,
   этапом обязательного согласования и маршрутизацией в существующий монтаж.
2. Добавить тонкие adapters для Claude Code, Codex и общих agents, чтобы не было трёх копий
   методологии.
3. Добавить три pressure-case eval, выполнить comparison с навыком и без него, затем записать
   assertions по фактическим ошибкам baseline.
4. Добавить публичную методологию, каталог навыков, README, архитектуру, changelog и структурный
   regression-тест.
5. Прогнать validation, unit test и human review статического отчёта eval; после обратной связи
   уточнить формулировки, не меняя пользовательские клиентские проекты.
