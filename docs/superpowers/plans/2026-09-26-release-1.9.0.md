  ````markdown
  # Монтаж из нескольких дублей

  Если вы записали ролик несколько раз (переснят хук, повторена середина, заново записан призыв), не
  нужно резать и склеивать дубли вручную. Агент соберёт один ролик из лучших кусков разных дублей.
  Тем же способом собирается один ролик из нескольких разных записей по вашему сценарию.

  Всё работает на вашем компьютере: расшифровка – локальный Whisper, склейка – FFmpeg. API-ключи не
  нужны.

  ## Как попросить агента

  Передайте агенту все файлы в одном сообщении и скажите, что это дубли одного ролика:

  > Вот три дубля одного ролика: take1.mp4, take2.mp4, take3.mp4. Собери лучший вариант.

  Для разных записей назовите, какой блок из какой записи взять:

  > Собери один ролик по сценарию: хук – intro.mp4, основная часть – main.mp4, призыв – cta.mp4.

  Если способ оформления не назван, агент сначала один раз спросит, как монтировать: уникальный
  Creative Motion, готовый стиль или по референсу. Дальше он работает сам и показывает вам полный
  preview.

  ## Что делает агент

  1. Создаёт проект из первого файла и добавляет остальные дубли. Они копируются в папку проекта,
     каждый расшифровывается локально. Ориентир: на Apple M1 Pro расшифровка занимает примерно треть
     длительности записи.
  2. Строит сводку фраз всех дублей с таймкодами.
  3. Выбирает лучший дубль для каждого смыслового блока: без оговорок и повторов, в порядке смысла.
     В сценарном режиме порядок и записи берутся из вашего сценария.
  4. Собирает новый исходник. Каждую границу куска движок сам ставит в тишину рядом, чтобы не
     резать слово, и пересчитывает субтитры без повторной расшифровки. Слова, которые Whisper
     «услышал» в тишине на краях кусков (например, «Продолжение следует»), в субтитры не попадают.
  5. Проверяет стыки по кадрам и по уровню звука. На стыках разных дублей ставит смену сцены
     (B-roll, графику, другой план), чтобы не был виден скачок.
  6. Дальше обычный путь: черновик, полный preview, ваше утверждение, финал.

  ## Что вы увидите в preview

  В пакете preview есть таблица выбора: блок, дубль, время в дубле и причина выбора. Если для
  какого-то блока хотите другой дубль, напишите это вместе с остальными правками, например: «хук
  возьми из второго дубля». Агент соберёт новый исходник и покажет новый полный preview.

  ## Требования к записям

  - Одинаковые FPS, размер кадра с учётом поворота и соотношение сторон пикселя. Проще всего
    снимать все дубли на одно устройство с одними настройками.
  - В каждом файле есть звук.
  - Если файлы не совпадают, команда остановится до копирования и объяснит причину. Перекодировать
    ваши файлы без вашей просьбы агент не будет.

  ## Если что-то пошло не так

  - **Расшифровку прервали.** Команда назовёт файлы, которые остались от прерванного запуска;
    агент удалит их и повторит.
  - **Рядом с границей нет тишины.** Движок печатает такую границу как `no pause near`: он не
    нашёл паузу, до которой можно дойти, не задев другое слово. Агент проверит этот стык и при
    необходимости выберет другую границу.
  - **Хочется вернуться к прошлому варианту.** Каждая сборка – новая версия исходника
    (`input/source-v02.mp4`, `input/source-v03.mp4` и так далее). Прошлые версии не
    перезаписываются.

  ## Для тех, кто запускает команды сам

  ```bash
  automontage takes add --project-dir projects/<id> --file take2.mp4 --file take3.mp4
  automontage takes pack --project-dir projects/<id> > projects/<id>/edit/takes-packed.md
  automontage master --project-dir projects/<id> --edit edit/v02-takes.json
  ```

  Формат `edit/vNN-takes.json` и флаги – в [README](../README.md#монтаж-из-нескольких-дублей).
  Полный маршрут агента – в
  [`skills/reel-turnkey/references/takes-selection.md`](../skills/reel-turnkey/references/takes-selection.md).
  ````

- [ ] **Step 1:** записать во временный файл сессии (не в репозиторий), затем проверить на U+2014, личные пути и ссылки на `blob/v1.9.0/...`:

  ````markdown
  ## Что нового

  ### Монтаж из нескольких дублей

  Записали ролик несколько раз? Передайте агенту все дубли – он соберёт один ролик из лучших кусков. Резать и склеивать вручную не нужно.

  - Агент локально расшифровывает каждый дубль, строит сводку фраз и выбирает лучший дубль для каждого смыслового блока: без оговорок и повторов, в порядке смысла.
  - Новый исходник собирается одной склейкой FFmpeg в новую версию проекта. Прошлые версии не перезаписываются, субтитры пересчитываются без повторной расшифровки.
  - В пакете preview есть таблица «блок – дубль – причина». Другой дубль можно попросить вместе с остальными правками.

  ### Разрезы в паузах, а не в словах

  Whisper часто «прячет» паузы внутрь слов, поэтому граница по его таймингам может отрезать кусок слова. Теперь движок сам находит тишину рядом с каждой границей (не дальше 0.25 с) и режет в ней:

  - разрез не перескакивает через другое слово: короткие «да», «И», «Не» не теряются, а вырезанное «эм» не возвращается;
  - границы, у которых рядом нет безопасной тишины, движок печатает (`no pause near`), и агент проверяет их по уровню звука до черновика;
  - слова, которые Whisper «услышал» в тишине на краях кусков («Продолжение следует»), не попадают в субтитры.

  ### Один ролик из разных записей по сценарию

  Тем же маршрутом собирается ролик из нескольких разных записей: скажите агенту, какой блок из какой записи взять, и он соберёт их в порядке сценария. На стыках разных записей агент ставит смену сцены, чтобы не было видно скачка.

  ## Исправлено

  - `automontage master`, `--tighten` и вырезание пауз снова работают с FFmpeg 9: filter script передаётся через `-/filter_complex` для FFmpeg 7+ и через `-filter_complex_script` для 6.x.
  - `automontage master` принимает исходник с метаданными поворота.
  ````
