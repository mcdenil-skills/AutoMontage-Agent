# Проектные навыки AutoMontage-Agent

Канонические инструкции навыков лежат в `skills/<name>/`. Тонкие адаптеры в
`.agents/skills/`, `.claude/skills/` и `.codex/skills/` делают один и тот же навык доступным
разным агентам без дублирования длинных инструкций.

## reel-from-donor

Навык превращает полезный разговорный Reels/Short/TikTok в авторский ролик с карточками.
Он не копирует донора: сначала строит карту конкретных смыслов, проверяет факты, обязательно
согласует CTA, дизайн, формат и длину, а затем показывает только тексты карточек. Графика,
анимация и монтаж начинаются после явного утверждения текстов.

Центральная карточка должна дать зрителю конкретный способ повторить фишку — ссылку,
настройку, шаблон или готовый не-технический промпт. Общие советы и неподтверждённые цифры
не проходят контентный контракт. Полная методология: [Reels из полезного донора](../docs/REEL-FROM-DONOR.md).

Пример запуска:

> Вот ссылка и транскрипт чужого Reels. Сделай из него мой ролик в карточках, но сначала
> разложи смысл и спроси CTA, дизайн и формат.

Новые навыки подхватываются при новом запуске агента. Если автоматический триггер не сработал,
назови навык явно: `$reel-from-donor`.

## reel-turnkey

Навык «ролик под ключ» ведёт весь lesson-процесс:

1. Проверка исходника и кадрирования.
2. Создание отдельной project-папки и локальная транскрибация.
3. Настоящий Remotion draft-preview и один полный пакет согласования.
4. Финальный рендер только после явного утверждения.
5. Версии рендера без перезаписи прошлых вариантов.
6. Музыка с sidechain-ducking и финальный QA.

Он также ведёт пакет вертикальных Reels: создаёт отдельный workspace на каждый выход, связывает
варианты одного хука общей неизменной основой, готовит 3–5 поэтапных векторных объяснений на
ролик длиной 2–3 минуты и показывает один пакет preview/QA для согласования. Полные рендеры в
одном checkout выполняются последовательно. Операционная инструкция:
[`docs/BATCH-REELS-WORKFLOW.md`](../docs/BATCH-REELS-WORKFLOW.md).

Обычный запуск использует текущую подписку Claude Code/Codex и не запрашивает provider
API-ключи. OpenAI API допустим только после отдельной просьбы пользователя сгенерировать
изображение; локальная транскрипция, draft, preview и финальный монтаж ключей не требуют.

Во время клиентского монтажа навык меняет только `projects/<id>/`. Если общей возможности нет,
она оформляется отдельной задачей движка, а не разрабатывается внутри активного ролика.

Пример запуска в новом чате:

> Собери ролик под ключ из `/path/to/video.mp4`. Формат вертикальный Reels. Музыка современная ритмичная без вокала. Остальное по дефолтам.

Новые навыки подхватываются при новом запуске агента. Если автоматический триггер не сработал, назови навык явно: `$reel-turnkey`.

## Что попадает в открытый репозиторий

В Git попадают сам навык, публичная тема `lesson-neutral`, семь сцен, схемы и тестовые запросы.
В Git не попадают `projects/`, внешние бренд-паки, исходники, транскрипты, музыка, рендеры,
ключи и локальная память.
