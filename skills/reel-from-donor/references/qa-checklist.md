# QA: Reel из донора

- [ ] CTA, дизайн, формат и длина были явно согласованы до дизайна.
- [ ] У каждой карточки есть источник в карте донора или первоисточнике.
- [ ] Нет выданных за факты обещаний, процентов и цифр донора без проверки.
- [ ] Центральные карточки содержат конкретное действие, ссылку, настройку или готовый промпт.
- [ ] Нет терминальных команд для нетехнической аудитории без отдельного запроса.
- [ ] Текст совпадает с утверждённым пакетом карточек.
- [ ] Новые элементы анимированы по отдельности; нет только масштабирования статичного экрана.
- [ ] На каждом кадре входа/выхода видимый край текста, карточки, подчёркивания и плашки не
      выходит за 1080×1920: минимум 70 px слева, 130 px справа, 250 px сверху, 420 px снизу.
- [ ] Нет отрицательного `left`/`translateX` за край экрана: эффект входа остаётся внутри
      безопасного контейнера.
- [ ] Карточки читаются в мобильной safe zone и не перекрывают лицо без осознанного blur.
- [ ] Аудио соответствует брифу; музыка и эффекты не добавлены самовольно.
- [ ] Preview просмотрен полностью; final создан только после явного утверждения.
